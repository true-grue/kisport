# Семестровый проект

П.Н. Советов, РТУ МИРЭА

Разработка простой кроссплатформенной ретро-игры.

- Тема игры выбирается самостоятельно или из списка [old-games.ru](https://www.old-games.ru/catalog/?year=1960&year2=1985&sort=year&o=a).
- Архитектура игры: низкоуровневое ядро и платформо-независимая игровая логика.
- Язык реализации ядра: только системный (C, C++, Rust, Zig, Ada, ...).
- Логика исполняется либо через собственную ВМ + интерпретатор/транслятор, либо через готовый скриптовый движок (Lua, Lisp, Forth, ...).

### Семестровый проект. Платформы

- Процессор (мин. 2): Отличающиеся разрядностью и/или порядком байт. Ретро-процессоры (Z80, 6502, ...), современные, микроконтроллеры.
- Графика: терминал, ретро-режимы, современная графика.
- Ввод: клавиатура, мышь, touch-интерфейс.
- ОС (мин. из 3 категорий): ретро (DOS, AmigaOS, ...), Unix (Linux, NetBSD, ...), Windows, Web (HTML/JS, WASM, ...), Android, bare-metal (Arduino, загрузочный сектор, ...).

### Семестровый проект. Прочее

- Нельзя использовать готовые игровые фреймворки (Unity, Godot, ...), только библиотеки не выше уровня SDL. Скриптовые движки разрешены только для игровой логики.
- Автоматизированное тестирование: модульное + один продвинутый метод (фаззинг, тестирование свойств, тестирование по модели).
- Стандартная система сборки (make, CMake, ...)
- Публичный git-репозиторий с детальной историей коммитов.
- Документация в readme.md.
