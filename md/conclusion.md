# Заключение {-}

В данном учебно-методическом пособии рассмотрены вопросы кроссплатформенной адаптации ПО, в том числе приложений, работающих с графикой, на основе переносимого и платформозависимого модулей.

В частности, рассмотрен способ переносимой реализации функции для отладки ПО на языке C, позволяющей просматривать значения байт переменных и структур в том порядке, который принят на целевой платформе, с учётом выравнивания данных и других особенностей целевой платформы. Рассмотрен способ реализации кроссплатформенного приложения с поддержкой вывода графики на ОС Windows, ОС Linux и в веб-браузере, основанный на использовании библиотеки SDL3 и компилятора Emscripten. Рассмотрен способ переноса существующей игры, написанной на языке C, на новую платформу с TUI, с поддержкой вывода ASCII-графики в терминал, на примере портирования переносимой версии игры Doom.

Кроме того, рассмотрены задачи для итоговой проверки знаний студентов, такие как: задача на тему преобразования структуры данных в массив байт с учётом архитектурных особенностей целевой платформы; задача на тему разбора массива байт, содержащего структуру данных, с учётом особенностей той платформы, на которой структура данных была преобразована в массив байт.

Практические навыки, приобретённые в процессе решения задач, рассматриваемых в пособии, необходимы при решении задач разработки ПО, таких как верификация требований, проектирование архитектуры и реализация кроссплатформенных программных систем, способных функционировать на разных ОС и поддерживающего различающиеся процессорные архитектуры.
